# X 粉丝数显示（Chrome 插件）

在 X 的信息流、关注者 / 正在关注列表、搜索结果等页面里，直接在每个用户名的下方显示一行蓝色小字「粉丝 X万」，不用再点进主页去看。

## 原理

和 [@yiren_ai](https://x.com/yiren_ai) 那条推文里说的一样：**X 网页自己发出的 GraphQL 请求里，本来就带了每个用户的 `followers_count` 字段**，根本不需要申请 API。

- `inject.js` 以 MAIN world 在页面最早期注入，劫持 `window.fetch` / `XMLHttpRequest`，从 X 自身请求的返回数据里提取 `{screen_name, followers_count}`，通过 `postMessage` 传给内容脚本；
- `content.js` 维护一张「用户名 → 粉丝数」表，用 `MutationObserver` 监听动态加载的推文和用户卡片，在用户名下方插入蓝色徽标；
- 数字格式化：≥1 万显示 `17.6万`，＜1 万显示千分位 `1,874`。

全程只读 X 页面自己的网络响应，不发任何外部请求，不需要登录态之外的任何权限。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`，右上角打开「开发者模式」；
2. 点击「加载已解压的扩展程序」，选择本文件夹；
3. 打开 [x.com](https://x.com)，刷信息流即可看到每个账号下面的粉丝数。

> 需要 Chrome 111+（用到了 Manifest V3 的 `world: "MAIN"` 注入）。

## 文件结构

| 文件 | 说明 |
|---|---|
| `manifest.json` | 插件清单（MV3，无任何敏感权限） |
| `inject.js` | 页面上下文脚本：拦截 GraphQL 响应、提取粉丝数 |
| `content.js` | 内容脚本：渲染「粉丝 X万」徽标 |
| `icons/` | 插件图标 |

## 已覆盖的页面位置

- 首页 / 时间线里的每条推文作者
- 关注者、正在关注、Verified Followers 等用户列表（`UserCell`）
- 搜索页、通知页中出现的用户卡片

## 注意

- 粉丝数是随页面滚动、请求返回逐步出现的，刚打开时先看到「粉丝 …」，数据到了会自动刷新；
- 数字来自 X 网页自己的接口返回，和你点进主页看到的粉丝数一致；
- X 改版（DOM 结构或接口字段变化）可能导致插件失效，届时需要更新选择器。
